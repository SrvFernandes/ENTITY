# Contributing to ENTITY

## Conference Submissions

### OpenID Well-Known Conference 2027
- **CFP Deadline**: Rolling until October 2026
- **Event Dates**: 2-4 February 2027
- **Submission Type**: Interoperability challenge
- **Focus Areas**:
  - Authority/provenance boundaries vs digital credentials
  - Sealed-vector reproduction across languages
  - External counterexample collection

### FOSDEM 2027
- **Devroom Proposal Deadline**: 4 October 2026
- **Event Dates**: 3-4 February 2027
- **Submission Type**: Cross-project collaboration
- **Topic**: "Verifiable authority, provenance and portable state"
- **Requirements**: Minimum 2 named devroom managers

## Submission Guidelines
- All submissions must be technical, not promotional
- Prefer collaborative formats over solo presentations
- Include clear interoperability challenges
- Reference existing test vectors where applicable
