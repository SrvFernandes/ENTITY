# Bounty Program Templates

## How to Submit
1. Open a GitHub issue with `[bounty]` label
2. Include clear acceptance criteria
3. Reference this template in the issue body

## Template
```markdown
### Bounty Details
- **Category**: [clean-environment/reproduction|documentation|test-vector|registry|verifier]
- **Estimated Value**: [USD amount]
- **Acceptance Criteria**:
  - [ ] Verifiable evidence submitted
  - [ ] Meets all requirements
  - [ ] No hash/vector modification

### Submission Requirements
- **For code**: PR with passing tests
- **For docs**: Merged PR with clear improvements
- **For test vectors**: JSON/YAML with counterexamples

### Validation
- BTG maintains final approval rights
- Payment does not imply validation
```
